# Metaprompting — Prompt Design Guidelines

Before designing any prompt, bear in mind that your training ended months ago and recommended prompting techniques may have changed. Current models include Gemini 3, Claude 4.5, and GPT 5.2. There is no value in citing older models or referencing them. Therefore, before designing any prompt you must search for relevant, up-to-date information. **Nothing prior to mid-2025**. You must review current sources such as:

https://ai.google.dev/gemini-api/docs/prompting-strategies

https://platform.openai.com/docs/guides/prompt-engineering

https://help.openai.com/en/articles/10032626-prompt-engineering-best-practices-for-chatgpt

https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/overview

https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/claude-4-best-practices

https://platform.claude.com/docs/en/resources/prompt-library/library

https://code.visualstudio.com/docs/copilot/customization/prompt-files

https://code.visualstudio.com/docs/copilot/customization/custom-instructions

When searching the internet for information on prompt design, be careful to focus on official and academic sources, as there are many outdated recommendations and many recommendations that are not backed by evidence.
