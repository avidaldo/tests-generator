# Stage 5 automatic reviewer

Stage 5 consist in a human review of the questions generated in stage 4, but the reviewer can mark some questions as "Revisar" for using this automatic reviewer to complete the question and make a first review. 


For all questions in a temporal session of stage 4, find those in "Revisar" state and apply the following:
- Complete them creating the necessary new distractor until 6; follow the distractor design strategies defined in the documentation.
- Make a complete review that they are sound and rigurous, follow the stablished rules for questions
- Keep the state of those questions as "Revisar". Don't change that. They still will require another human review.
- Don't touch any other question.
